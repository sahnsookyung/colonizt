# Sound Assets

The eleven short cues in `packages/web/public/sounds` are original procedural audio, generated by `scripts/generate-sounds.py` with Python's standard library. No external samples or audio dependencies are used. Run `python3 scripts/generate-sounds.py` from the repository root to reproduce the checked-in WAV files.

The sound palette follows the illustrated island UI: soft wood taps for selection, dice, and construction; low-passed paper movement for cards and discards; and restrained, low-register pitched tones for progress and turn changes. The game-over cue resolves gently without a fanfare. Soft attacks, quiet room reflections, and limited upper harmonics keep repeated actions comfortable. Each cue has its own rhythm and pitch shape so the event remains recognizable at modest volume.

| File | Cue |
| --- | --- |
| `ui-select.wav` | Single soft wood tap for intentional selections |
| `dice-roll.wav` | Five settling wooden dice contacts |
| `build-road.wav` | Two close wooden placements |
| `build-settlement.wav` | Wood placement followed by a warm two-note response |
| `upgrade-city.wav` | Deeper placement and three rising mellow tones |
| `trade.wav` | Two conversational taps with a paper movement |
| `dev-card.wav` | Card brush and a gentle two-note reveal |
| `thief.wav` | Low, unresolved clay-like resonance |
| `discard.wav` | Paper shuffle and subdued closing tap |
| `turn-handoff.wav` | Two descending tones |
| `game-over.wav` | Slow, resolved four-note chord |

The web client maps confirmed game events to one cue per action batch, and only plays ordinary action events when they affect the human player. Immediate selection taps are used for intentional controls. Playback stays browser managed and may be blocked until a user gesture; this never blocks gameplay.
